5. JavaScript code defense

The script chooses the menu button with the button variable and the navigation list with the list variable. It adds the js class to the document so the collapsed navigation will only apply when JavaScript is available. In the beginning, the menu button is shown and the navigation list is hidden for the more narrow layout. When the button is clicked, the script checks the aria-expanded and keeps that value together with whether the navigation list is hidden or visible. The click event moves this toggle using the native button. The keydown event checks for the escape key, and when the menu is open, escape closes the list, changes aria-expanded back to false, and returns focus to the menu button with button.focus().
